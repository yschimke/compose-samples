Each row pairs a jetcaster-wear component with its declared jetcaster parallel (the parallel field in the catalog spec). Both renders are static thumbnails — the left from this branch, the right baked from the design-artifacts/jetcaster branch — and each links to the live preview server on click, where the component re-renders under other themes / locales / devices. A parallel that isn't catalogued in jetcaster yet is flagged unpaired. Components with no parallel on either side are listed below the table.
